## Proyecto nuevo: FAUVOR Flow

Un proceso demostrable: **consulta → análisis → tarea → aviso**. Incluye tres flujos, historial por paso, reintentos y tareas. La demo usa reglas locales; el servidor Node.js guarda datos en SQLite y permite configurar IA y Telegram de forma opcional.

[Ver código, pruebas y documentación](https://github.com/Franc-Devel/system-flow)
